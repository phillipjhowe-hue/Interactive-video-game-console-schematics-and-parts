# Console Repair Atlas v1.2.0 (previous version)

Clickable resistors & capacitors — kept here for anyone who wants this version. **For the latest version, see the [Releases](https://github.com/phillipjhowe-hue/interactive-video-game-console-schematics-and-parts/releases) page or the main [README](https://github.com/phillipjhowe-hue/interactive-video-game-console-schematics-and-parts#download).**

The Windows zip is larger than GitHub's 100 MB file limit, so it's stored in 3 parts.

## Download and rebuild

1. Download all the files in this folder into the same folder on your PC (click each file, then **Download raw file**):
   - `ConsoleRepairAtlas-v1.2.0-win64.zip.001`
   - `ConsoleRepairAtlas-v1.2.0-win64.zip.002`
   - `ConsoleRepairAtlas-v1.2.0-win64.zip.003`
   - `JOIN-PARTS.bat`
2. Double-click **JOIN-PARTS.bat**. It rebuilds `ConsoleRepairAtlas-v1.2.0-win64.zip` and checks it is intact.
3. Unzip it and run `Console Repair Atlas.exe`.

**Manual alternative** (Command Prompt in that folder):

```
copy /b ConsoleRepairAtlas-v1.2.0-win64.zip.001+ConsoleRepairAtlas-v1.2.0-win64.zip.002+ConsoleRepairAtlas-v1.2.0-win64.zip.003 ConsoleRepairAtlas-v1.2.0-win64.zip
```
